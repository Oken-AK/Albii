# Albii（Android アルバムアプリ） 計画書

## 目的・ゴール

端末内の写真・動画を快適に閲覧するAndroidアルバムアプリを作る。
- 並び順（下が最新／上が最新）を設定で切替
- フルサイズ表示から上スワイプで写真の詳細情報（EXIF・レンズ・日時・画像データ等）を表示。表示項目は設定でチェックしたものだけ
- AFポイント（ピント位置）を対応機種のみ可視化
- 完全ローカル動作（INTERNET権限は追加しない）

## 背景・前提

- 対象: Android 14（API 34）以上、スマホ・タブレット両対応
- Kotlin + Jetpack Compose（Material 3）、UI言語は日本語のみ
- リポジトリルートに直接配置（既存構成のまま）
- アプリ名 Albii / パッケージ名 `com.oken.albii`（仮）
- 技術選定の理由は [ADR-0001](../docs/adr/ADR-0001-android-tech-stack.md) を参照

## 機能要件

| ID | 要件 |
|----|------|
| F-01 | 設定で並び順「下が最新」「上が最新」を切替（全体統一）。初期値: 上が最新 |
| F-02 | 表示形式: グリッド / 日付見出し / 月見出しを設定で選択。初期値: グリッド＋日付 |
| F-03 | 高速スクロールバー必須（ドラッグで日付・月へジャンプ） |
| F-04 | 画像・動画の表示対象を個別にON/OFF（同時・片方のみ可）。初期値: 両方 |
| F-05 | 動画はアプリ内フルスクリーンビューアで再生 |
| F-06 | 画像はフルスクリーン表示、スワイプで移動、ピンチズーム |
| F-07 | 端末のフォルダ（バケット）単位で絞り込み |
| F-08 | 独自アルバム: アプリ内DBのみ（端末フォルダは作らない） |
| F-09 | お気に入り: アプリ内DBのみ |
| F-10 | 削除はアプリ内ゴミ箱へ。保持30日、経過後に完全削除 |
| F-11 | ゴミ箱から復元可能 |
| F-12 | 編集は外部編集アプリへIntentで受け渡し |
| F-13 | 共有ボタンで他アプリ・Quick Share へ（FileProvider経由） |
| F-14 | 「全ての写真・動画」へのアクセス権限を要求（部分アクセス非対応） |

### 写真の詳細情報パネル

- フルサイズ表示で上スワイプ → ボトムシートで詳細情報を表示
- 表示項目は設定でチェックしたものだけ（項目ごと・カテゴリ単位で一括ON/OFF）
- 初期ON: 撮影条件・レンズ基本・日時・画像データ。シリアル番号・GPS座標は初期OFF（OPT-IN）
- AF枠: MakerNote由来のAF座標を対応機種のみ画像上に描画。非対応機種は非表示（エラーにしない）

#### カテゴリと方針

| カテゴリ | 内容 | 方針 |
|---------|------|------|
| 1. 撮影条件 | ISO・SS・F値・EV・露出プログラム・測光・WB・フラッシュ・手ブレ補正・シーン | 実装（ExifInterface） |
| 2. レンズ・光学 | 焦点距離・35mm換算・画角・最大絞り・レンズ名 | 実装（レンズ名は機種依存） |
| 2. 計算値 | 被写界深度・超焦点距離・手ブレ限界 | 実装（被写体距離が無い機種は算出不可表示） |
| 3. 機材 | Make・Model・Software・ファーム。シリアルはOPT-IN | 実装 |
| 4. 日時・位置 | 撮影日時（TZ付き）・GPS・高度・方位 | 実装（GPSは初期OFF） |
| 4. 天文 | 太陽位置・日の出/入り・ゴールデンアワー・月齢 | 実装（オフライン計算） |
| 4. グルーピング | 同じ場所・同じ日の写真のまとまり | 実装 |
| 5. 画像データ | 解像度・形式・サイズ・ビット深度・ICC・Orientation | 実装 |
| 6. 編集履歴 | XMP・Software タグ | 後続A |
| 7. 画質解析 | ヒストグラム・白飛び/黒つぶれ・ブレ/ノイズ推定 | 後続B（バックグラウンド＋キャッシュ） |
| 8. 深度・ポートレート | XMPの深度マップ、背景ぼかし | 後続A（機種依存） |
| 9. 被写体・シーンML | 人物・物体タグ | 後続C（顔認識・名前付けは初期見送り） |
| 10. 連写・類似 | 撮影時刻近接＋知覚ハッシュ | 後続B |
| 11. 統計 | 機材・焦点距離・ISO別の傾向 | 後続B |
| 12. MakerNote | メーカー独自情報 | 後続C（メーカー単位で段階対応） |

#### 対象外

- 地名（逆ジオコーディング）・天気: 通信が必要なため
- レンズ歪み補正プロファイル照合: 外部DBが必要なため

## 非機能要件

| ID | 要件 |
|----|------|
| N-01 | 数万枚規模でもスムーズにスクロール |
| N-02 | Coil によるサムネイルのメモリ＋ディスクキャッシュ |
| N-03 | Paging 3 で必要範囲のみ読み込み |
| N-04 | 通信なし（INTERNET権限不要） |
| N-05 | Room（お気に入り・独自アルバム・ゴミ箱・解析キャッシュ）、DataStore（設定） |
| N-06 | 実ファイル削除は MediaStore の削除リクエスト（システム確認）経由 |

## 実装フェーズ

| Phase | 内容 | 完了条件 |
|-------|------|---------|
| 0 | 雛形（Gradle・Compose・Hilt要否） | 空画面がビルド・起動 |
| 1 | 権限 + MediaStore + グリッド（並び順・日付/月・スクロールバー） | 大量データでスムーズ |
| 2a | 画像/動画ビューア、共有・外部編集Intent | 開いて共有できる |
| 2b | 詳細シート＋基本カテゴリ＋設定のチェックUI | 選んだ項目だけ表示 |
| 2c | 計算値・天文・グルーピング | 単体テストで既知値と一致 |
| 2d | AF Spike → 対応メーカーのAF枠オーバーレイ | 実写真で正しい位置 |
| 3 | フォルダ一覧、表示対象フィルタ | フォルダ単位で絞り込める |
| 4 | Room: お気に入り・独自アルバム | アプリ内に保持 |
| 5 | ゴミ箱（削除・復元・30日完全削除） | 一通り動く |
| 6 | 設定画面の仕上げ・テーマ・タブレット対応 | 再起動後も設定保持 |
| 7 | 性能確認・仕上げ | DoD満たす |
| 後続A | XMP編集履歴・深度マップ | 対象ファイルで表示 |
| 後続B | 画質解析・類似写真・統計 | バックグラウンド解析・キャッシュ |
| 後続C | ML被写体タグ・MakerNote拡張 | 方針確定後に対応 |
