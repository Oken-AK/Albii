# ADR-0004: ジェスチャー処理の方針とアプリ内の写真選択

- ステータス: Accepted
- 日付: 2026-10-14

## 背景

実機確認（ラウンド2）で次の不具合が出た。

- グリッドのピンチで列数が変わらない
- 全画面表示で横スワイプできない
- アルバムへの追加がシステムのピッカーになり、UI が揃わない

原因は、親の `detectTransformGestures` が Main パスで動くため、子の `LazyVerticalGrid` や `HorizontalPager` が先にドラッグを消費していたこと。

## 決定

1. ピンチは `awaitEachGesture` と `PointerEventPass.Initial` で親が先に受け取る。2本指のときだけ消費する。
2. ビューアは等倍のとき1本指を消費せず Pager に渡す。拡大中だけパンを自前で消費する。
3. アルバムへの追加はシステムの Photo Picker を使わず、`MediaStore` から読んだ一覧を複数選択する画面（`MediaPickerScreen`）で行う。
4. スクロールバーは通常時も透明度を下げ、スクロール後 1.5 秒で非表示にする。

## 理由

- フレームワークの `calculateZoom` などを使えば、独自の判定ロジックは不要になる。
- Initial パスなら子より先に判定でき、標準のジェスチャー仕様と揃う。
- アプリ内で完結させることで、アルバムの見た目と操作を統一できる。

## 影響

- 2本指の操作は、子のスクロールより先に親が消費する。
- 写真選択画面は `MediaStore` の全件を読むため、件数が多い端末では初回表示が遅くなる可能性がある。
- 1.5 秒の自動非表示は仮の値。実機で調整する。
